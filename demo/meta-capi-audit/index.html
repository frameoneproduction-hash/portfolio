2. Deduplication checklist

  • Same event_name in browser and server (e.g. Purchase, not purchase)
  • Same event_id: pixel eventID equals server event_id for each event
  • Server event sent within 48 hours of the browser event
  • fbp and fbc cookies passed to server events
  • action_source = website, event_source_url and event_time (seconds) present
  • Checkout page cached, so event_id changes on refresh (see InitiateCheckout)
  • No second pixel on the site (theme, another plugin or GTM)

3. Matching and consent

  • Advanced matching: hashed email, phone, name, city, postal code, country on Purchase
  • external_id sent for logged-in customers
  • Event match quality on AddToCart lower than on Purchase: email is not known before checkout, that is normal
  • Consent: no pixel requests before the visitor accepts marketing cookies
  • Server events sent for visitors who declined: confirm with your consent policy

4. Events Manager diagnostics

  • “Content IDs don't match catalog” on ViewContent (see table)
  • “Low deduplication rate” on InitiateCheckout
  • No “missing currency” or “invalid value” warnings
  • Domain verified, events from own domain only
